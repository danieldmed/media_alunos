# Média alunos

Este projeto foi desenvolvido no contexto das aulas do curso de Desenvolvimento de Sistemas, com o objetivo de aplicar os conceitos aprendidos até o momento, principalmente no que se refere à Programação Orientada a Objetos (POO). O desafio consistia em criar um programa simples, mas eficaz, capaz de calcular a média das notas dos alunos.

O sistema foi desenvolvido utilizando a linguagem de programação Java, uma das mais utilizadas no desenvolvimento de sistemas, devido à sua robustez e versatilidade. A ideia principal do projeto é fornecer uma ferramenta prática para calcular a média de notas, permitindo ao professor ou à instituição de ensino acompanhar o desempenho dos alunos de forma eficiente.
